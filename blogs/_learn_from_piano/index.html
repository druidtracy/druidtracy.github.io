學琴這兩年來教會我的事

2026-07-04·1 分鐘·
目錄

2023 年秋天，我開始學琴。

起初，我以為學琴是一件很單純的事：看懂譜、把音彈對、練熟一首曲子，再進入下一首。只要投入足夠的時間，就應該看得見進步。

這很像我原本面對許多事情的方式。我習慣先理解規則、找到方法，再用效率完成目標。這個模式讓我能快速上手，也讓我很容易把「做完」誤認成「學會」。

鋼琴卻不斷拆穿這件事。

1. 手指記住了，不等於真正理解 #

我曾經一天練習一、兩個小時，也能把曲子彈到足以上台。但後來回頭看，真正清楚知道自己正在聽什麼、修正什麼的時間，有時只有幾分鐘。

其餘的練習，可能只是依賴熟悉感和肌肉記憶，一次又一次把曲子跑完。

老師反覆提醒我的，不只是音符，而是重量如何落下、重心如何移動、聲音是否真的被自己聽見。這些事情無法靠「更用力」解決。越想控制，有時聲音反而越僵硬；越急著證明自己會了，越聽不見真正的問題。

我開始明白，一項能力如果只能在熟悉的情境裡被重複，卻不能被拆解、理解和調整，那可能還不是我真正能帶走的能力。

2. 長時間投入，不代表一直保持覺察 #

我能長時間投入一件事，這一直是我相信的優點。

但練琴讓我發現，投入的時間和有效的注意力並不相等。我可能坐在琴前很久，心裡想的卻只是把曲子順利彈完，而不是聽見聲音、辨認問題，再有意識地做出調整。

這也暴露了我的思考習慣：我喜歡可掌握的進度，面對模糊時會本能地尋找標準答案；我對自己有要求，也很容易把要求變成催促。

真正困難的練習，不是把相同的動作做更多次，而是在每一次重複裡，仍然知道自己正在做什麼。

3. 休息不是中斷學習，而是學習的一部分 #

過去的我很容易把堅持理解成「不能停下來」。

即使身體不舒服、練習效果開始下降，我仍會覺得只要再努力一點，就能克服問題。但鋼琴是一件很誠實的事。當身體緊繃、注意力渙散時，再多的意志也無法換來更好的聲音。

我才逐漸明白，休息不是鬆懈，也不是背離目標。知道什麼時候應該停下來，讓身體和頭腦有時間沉澱，本身也是判斷力的一部分。

有些成長並不是更用力，而是願意放慢。

4. 重新詮釋什麼是「展現自己」 #

比賽和上台，讓我重新理解了「展現自己」。

過去的我容易把公開表現看作成果驗收：彈得好，代表準備充分；彈得不好，就像能力被否定。上台是一個終點，也像是對這段努力的最終評分。

但站到聽眾面前之後，我慢慢懂得，表現不是交出一個無瑕的答案，而是如實呈現自己走到了哪裡。

緊張、失誤和不穩定，不會抹去此前的練習。它們只是讓我看見，在離開熟悉環境之後，哪些能力已經屬於我，哪些地方仍需要再理解。

上台因此不再只是最終驗收，而成為了學習過程中的一次驗證。

5. 不再只用績效看待一件事 #

學琴也沒有讓我從此不再比較。

我仍然會看見別人的速度、天分和成果，也仍然可能因此懷疑自己的步伐。我習慣從結果判斷一件事是否值得：學了多久、會彈幾首曲子、是否參加比賽、表現得夠不夠好。

不同的是，我開始知道，容易衡量的東西不一定就是最重要的東西。

真正重要的，不只是我最後彈成了什麼，而是我是否知道自己為什麼繼續、正在練習什麼，以及這段投入如何改變了我。

比較很容易，辨認自己的路比較難。

6. 暫停，不等於否定曾經的投入 #

到了 2026 年，我決定暫停鋼琴課，把時間放到人生的下一個階段。

這不是因為學琴沒有結果，也不是因為我失去了興趣。剛好相反，是因為它給我的，早已超過會彈幾首曲子。

這兩年多，鋼琴教我的不只是如何成為一個更會彈琴的人，更教會我如何更誠實地看待自己。

我仍然重視效率，但不再把速度當成全部；仍然在意成果，但也開始看見過程裡的判斷與覺察；仍然會要求自己前進，卻逐漸明白，有些答案需要在放慢與傾聽之後，才會出現。

琴鍵留下的，也許不只是一段聲音。

它讓我看見自己的性格如何推動我，也如何限制我；讓我知道，真正能帶走的能力，不是把熟悉的事情重複得更快，而是在陌生與不確定裡，仍能保持清醒，知道自己正在做什麼。
