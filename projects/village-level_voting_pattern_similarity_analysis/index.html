前言 #

「章魚里」（又稱選情章魚哥）是指在台灣各項選舉中，其開票結果與最終全區或全國結果高度相似的村里，常用來作為開票時的趨勢觀察指標。

台灣知名指標性「章魚里」

  • 台北市士林區天玉里

    長期被媒體與民眾視為開票風向球，人口結構與台北市極為相似，在地方選舉中預測極具參考價值。閱讀 台灣英文新聞 了解天玉里開票與選情分析。

  • 新北市鶯歌區建德里

    人口結構具有新北市縮影的特點，歷年總統及公投開票結果常與大局吻合。 查看 中時新聞網 關於雙北章魚里盤點的報導。

研究問題 #

  1. 人口結構會變動、選舉有不同類型，將一個特定村鄰里訂為長年不變的章魚里是否具有其合理性?
  2. 章魚里其開票結果與最終結果高度相似的定義，似乎很模糊。是否有可能透過數據分析結果，來觀察各村里選舉結果與最終結果的相似度如何?

材料與方法 #

資料來源 #

中選會選舉及公投資料庫 2024 ー 第16任總統副總統選舉 資料，共計22個縣市、7700餘個村鄰里之各投開票所投票統計資料庫。

工具/程式語法 #

  • 使用Pandas與Sqlite建立資料庫

  • NumPy計算各村鄰里之餘弦相似度

  • 再用Gradio製作成品

  • 最後部署至Hugging Face Space上

    可藉由輸入縣市名稱(county)、鄉鎮市區名稱(town)及村鄰里名稱(village)，查詢各村鄰里之排名及其餘弦相似度。

分析方法 #

透過分別計算三組候選人在7700餘個村鄰里的得票率，與最終得票率之 餘弦相似度(Consine Similarity) ，來觀察與最終得票率相似的村鄰里有哪些。

\( similarity = cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \sqrt{\sum_{i=1}^{n} B_i^2}} \)

公式說明:

  • 分子 \( \mathbf{A} \cdot \mathbf{B} = \sum_{i=1}^{n} A_i B_i \) ：兩向量的內積

  • 分母 \( \|\mathbf{A}\| \|\mathbf{B}\| \)：兩向量的長度相乘，其中 \( \|\mathbf{A}\| = \sqrt{\sum_{i=1}^{n} A_i^2} \)

  • 數值範圍: 介於-1 到 1 之間，在正值範圍中則是介於 0 到 1 之間。

    • 1: 方向完全相同，夾角為0°。
    • 0: 正交/無關，夾角為90°。
    • -1: 方向完全相反，夾角為180°。

研究結果 #

將7700餘個村鄰里得票率與最終得票率之餘弦相似度，由高至低排序後，發現與最終得票率相似度最高的村鄰里不一定是長年被認定的村鄰里。

  • 相似度最高前三名村鄰里:
    南投縣草屯鎮中山里 (99.999998%)
    新北市土城區樂利里 (99.999997%)
    南投縣草屯鎮新豐里 (99.999993%)

  • 常見章魚里的排名:
    臺北市士林區天玉里 排名2482 相似度 99.241715%

    新北市鶯歌區建德里 排名979 相似度 99.750225%

結論 #

  • 本專案以 2024 年總統副總統選舉的村里層級得票資料為基礎，透過餘弦相似度量化各村里的候選人得票率分布與全國得票率分布之間的相似程度，並據此建立排名。分析結果顯示，相似度最高的村里不一定是過去媒體經常提及的指標性章魚里，例如臺北市士林區天玉里排名第 2,482 名，而新北市鶯歌區建德里排名第 979 名。這表示在本次選舉與本專案採用的衡量方法下，傳統上被視為選情指標的村里，並非必然與全國得票率最為相似。

  • 本次分析也顯示，「章魚里」的判定可以從經驗性的描述轉化為可量化的比較問題。然而，餘弦相似度衡量的是候選人得票率分布的相似程度，並不直接代表預測選舉結果的準確率；單次選舉的分析結果，也不足以判斷某個村里是否能長期反映全國選情。因此，章魚里的代表性仍須結合不同年度、不同類型的選舉資料進一步驗證。

  • 透過本專案，我將原始選舉資料經由 Pandas 與 SQLite 整理，再使用 NumPy 計算餘弦相似度，最後以 Gradio 建立查詢介面並部署至 Hugging Face Spaces，完成從資料處理、分析到應用部署的實作流程。這個專案不僅將模糊的「選情相似」概念轉化為可比較的數值，也呈現了資料分析方法在公共議題探索與資訊視覺化應用上的可能性。
